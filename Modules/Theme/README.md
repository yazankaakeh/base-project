# 🧩 Theme Module - Shared Assets

The **Theme module** provides shared static assets and utilities used across the application.

## 📦 Included Assets

- 🌍 Theme Build Assets

## 📁 Folder Structure

Modules/Theme/
└── Resources/
└── assets/
├── build/

## 🚀 Publishing Assets

To make the assets publicly accessible, run the following command:

```bash
   php artisan vendor:publish --tag=theme-assets
   ```

This will copy the files to:

public/build/ ← from Theme/Resources/assets/build/
